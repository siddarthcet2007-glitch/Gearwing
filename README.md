# GEARWING: Flight Protocol

A mechanical flight arcade game built with Python and Pygame,
designed around the **Gear + Flight** theme.

## Features
- Gear-themed obstacles
- Flight and collision mechanics
- Score tracking and best-score saving
- Wind-Up Boost ability

## Controls
- Space / Mouse Click: Fly
- E: Activate boost
- Escape: Quit

## Run locally
Install Python, then run:

```bash
pip install -r requirements.txt
python main.py
